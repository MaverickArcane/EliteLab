# Workspaces and layouts

The default tabs now have narrower jobs:

| Workspace | Main contents |
| --- | --- |
| Overview | Location, ship, cargo, recent activity, map, then compact credit history |
| Materials / Recipes | Saved recipes, requirements, exchanges, gathering, inventory, synthesis evidence and pinned build |
| Flight | Route planner, ship/location, map and activity |
| Ship | Full-width loadout, integrity and shield state |
| Trading | Cargo buyers and tracked selling route, cargo, secondary personal round trips |
| Carrier ops | Owner plans, crew task/party, stock and followed carrier |
| PTN desk | Independent route scouting, confirmation and public-hauling preparation |
| Mining | Mining sessions, ring/buyer search and cargo |
| Powerplay | Pledge, merits, targets, rare loop and combat |
| History | Credit balances, merit cycles and collection history |

Overview's credit chart uses the same journal history as History, for the current
or only commander over 30 days. It is a recorded balance curve, not a transaction
ledger or net-profit graph. Open History for filters or commander disambiguation.

Ship modules use restrained warning color for low integrity and text for powered
off modules. The shield strip shows Up, Down or Unknown. Player telemetry does
not provide a usable shield-strength percentage here; it never borrows a targeted
ship's percentage or pretends the Up state means 100%.

The map appears only in Overview and Flight by default. It remains available in
custom layouts. Existing saved layouts are preserved, including deliberate map
placement. Navigation does not rewrite your layout.

**Layouts** offers Custom plus three default preset tabs: Expedition, Rare goods,
and Second screen. Previously used preset tabs and named saved layouts remain
available. Layout > Additional presets retains the older templates without
filling every new installation's navigation with them. Arrow keys navigate tabs;
each preset/saved tab retains its own arrangement. Resetting a preset is explicit.

**Second screen** puts ship and location first, then cargo, merit rate and recent
activity. Height caps keep long lists inside their cards; there is no default map.
Resize/reorder the cards for your monitor and save the arrangement in that browser.

**Expedition** groups flight, synthesis and research tools. For a bio trip today,
use it for route preparation, fuel/FSD evidence, travel and required synthesis
materials. It does not yet track ScanOrganic sample chains, genetic diversity,
species payouts or first-footfall bonuses. A future bio view needs commander/body/
species identity and genuine sample/sale evidence before it can estimate progress
or value; manually planned stops are not biological discoveries.

**Rare goods** remains an optional layout. Powerplay's tracker, combat and rare
loop stay available; this release does not collapse distinct merit workflows
into one estimator. The Powerplay target and in-game reward checks remain part
of release acceptance.
