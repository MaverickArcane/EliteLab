# EliteLab 0.6.0 Beta 3

Rhino surface mining joins the Mining workspace, with saved locations, surface
navigation, collection tracking and the same sourced guide available to MCP.
This beta retains all Beta 2 security and private-playtest changes.

Python and adds EliteLab and Uninstall EliteLab to the Start menu. For an

## Mining changes

- Follow observed refined tonnes, the commodity breakdown, a collection chart,
  unloading progress and separate Rhino/ship cargo reports. Transfers preserve
  the deployment total.
- Browse two confirmed locations and six research leads. Wregoe JC-Y b57-0 A 1,
  PML 4 records six rigs deployed by the owner. Sources distinguish observed,
  reported and estimated rig counts. Depletion is a separate report.
- Save commander-local spots and navigate back using fresh same-body distance
  and bearing. Cached coordinates cannot restore directions after departure.
- Mark a location confirmed in one click while retaining its complete existing
  report, date and depletion flag. Forms reject writes after a commander switch.
- Read practical prospecting, placement, collecting, unloading and depletion
  instructions in the shared browser/MCP guide. Assistants have the same catalog,
  evidence, notebook tools and confirmation safeguards.
- Watch Materials gained this session alongside mining. Login boundaries preserve
  opening inventory, and repeated journal replay no longer doubles gained totals.

Cargo bars use the beta's existing constrained gauge renderer, preserving the
strict browser policy introduced in Beta 2. The Windows Start-menu uninstall
shortcut invokes the existing guarded uninstaller and retains saved user data.

## Install or update

1. Exit EliteLab from its tray menu before installing or uninstalling. Setup
   refuses to replace files while an instance is running.
2. Run the Beta 3 desktop installer to update the existing installation. For a
   fresh application install, first remove the older version through Windows
   Settings > Apps; then run this installer. Old versions may not have the new
   Start-menu uninstall shortcut.
3. Launch EliteLab and open Mining > Rhino surface mining. Existing user settings
   and saved data are retained by uninstall/reinstall; game journals are untouched.
4. Portable previews and staging profiles keep their data separately. Keep a
   backup before removing those folders; they are not imported automatically.

## Validation and limitations

The integrated beta passed 857 offline tests (11 skipped), the Rhino browser
check under the strict browser policy, Materials response-order/filter checks
and state-stream checks. Publication additionally requires the full staging
CI matrix, browser suites, native package builds and install/upgrade/uninstall
smoke tests. The Windows lifecycle
check verifies both Start-menu shortcuts, the uninstaller target and removal.

Confirmed means dated field evidence, not current reserves or guaranteed rig
capacity. No live rig hopper, extraction or replenishment telemetry is inferred.
Private multiplayer retains Beta 2's limits; a real host-plus-two-friends session
remains a player acceptance test. See [the mining guide](https://github.com/MaverickArcane/EliteLab/blob/v0.6.0-beta.3/docs/RHINO-MINING.md)
and [private staging instructions](https://github.com/MaverickArcane/EliteLab/blob/v0.6.0-beta.3/docs/STAGING.md).

Report issues with the exact beta version, platform, reproduction steps and a
redacted diagnostic ZIP. Do not attach credentials, settings files or journals.
